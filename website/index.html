Why TideBot

A studio, not a chatbot

Everything a serious agent operator needs — designed for people who want to own their stack.

🧠

Bring your own model

OpenRouter, Ollama, vLLM, xAI or any OpenAI-compatible endpoint. Swap providers per bot, per task — no lock-in, no markup on tokens.

🔌

1,500+ integrations, zero glue code

Composio-powered tools for GitHub, Slack, Notion, Gmail and hundreds more. Agents call real APIs with scoped credentials you control.

🔒

Sandboxed by default

File operations are confined to per-bot workspaces. Model output is treated as untrusted data — always.

🖥️

Local-first + cloud option

Run in a local sandbox, or give agents ephemeral cloud Linux desktops when a task needs a real machine.

⏰

Routines & triggers

Cron schedules, webhooks and event triggers — agents that act while you sleep and report back on their own schedule.

🎛️

A UI built for supervising agents

Live streaming sessions, tool-call timelines, approvals for sensitive actions, and full local logs. You always see what your agents are doing.

🛠️

Yours to fork

MIT licensed with an agent-engineering guide (AGENTS.md) so AI contributors — and humans — can extend it safely.
